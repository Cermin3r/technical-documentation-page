What is a Website?

A website is a collection of web pages that are accessible via the internet.

Each page is identified by a unique URL (Uniform Resource Locator).

HTML: The Bones of a Website

HTML (Hypertext Markup Language) is the standard markup language for creating web pages. It provides the structure and content of a website.

Every website is built using HTML elements, starting with the basic structure of a web page, called the boilerplate. An example boiler plate is below:

<!DOCTYPE html>
<html lang="en">
  <head>
    <meta charset="UTF-8" />
    <title>Document</title>
  </head>
  <body>

  </body>
</html>

CSS: The Skin of a Website

CSS (Cascading Style Sheets) is used to describe the presentation of a website. It controls the layout, colors, and fonts of a website.

Styles can be defined in various ways, including inline styles, internal style sheets, and external style sheets.

Inline styles are applied directly to an HTML element using the style attribute. An example is:

<h1 style="color: blue;">This is a heading</h1>

Internal style sheets are defined within the <head> section of an HTML document using the <style> tag. An example is:

<head>
  <style>
    h1 {
      color: blue;
    }
  </style>
</head>

External style sheets are separate CSS files that are linked to an HTML document using the <link> tag. An example is:

<head>
  <link rel="stylesheet" href="styles.css" />
</head>

In every case, the syntax of a CSS rule is the same: a selector followed by a declaration block: selector { property: value; }

CSS is how you create visually engaging websites. Some of the things that you can influence using CSS include:

  • Layout and positioning of elements
  • Colors and backgrounds
  • Fonts and text formatting

JavaScript: The Brain of a Website

JavaScript is a programming language that adds interactivity and dynamic behavior to websites. It allows developers to create engaging user experiences and handle complex functionality.

JavaScript can be used to manipulate HTML and CSS, handle user input, and create dynamic content.

JavaScript can be included directly in an HTML document using the <script> tag. For example:

<script>
  // JavaScript code goes here
</script>

JavaScript can also be included as an external file using the <script> tag with the src attribute. For example:

<script src="script.js"></script>

JavaScript is a powerful tool for creating interactive and dynamic websites. Some of the things that you can do with JavaScript include:

  • Form validation
  • Dynamic content updates
  • Animations and effects

Accessibility

Accessibility ensures that websites are usable by people with disabilities.

It involves implementing features that make content accessible to users with various impairments.
